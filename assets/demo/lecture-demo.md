# 可复现的研究：从讲稿到放映
## 为什么"讲稿即代码"?
- 文本是 source of truth：每一页都是构建产物，可 diff、可回滚
- <span class="aigc">保存可编辑的源码与构建过程，而不只是最终像素或放映录像</span>
- 改逻辑只改源稿，重新构建即可；视觉换肤只换主题文件

## 三分钟上手
- 拷贝引擎目录（纯 Python 标准库，零依赖）
- 用任意编辑器写 Markdown 讲稿
- 一条命令构建：单文件 HTML，双击即放映
  - 语法分两种方言，本页即方言 B（`---` 分页）
  - 引擎按内容自动识别，无需配置

# 排版与诚实标记
## 中文学术排版红线
- 正文行高 1.7，`line-break: strict` 避头尾
- 纯黑 #000 禁止：用带色相的深墨
- 标题编号写「N.」即可，不用 § 符号

## AIGC 如实标记
- 凡 AI 扩写的内容，源稿中用 aigc 标签包住（见 dialect-syntax.md）
- <span class="aigc">例如这一句：由 AI 补充的背景说明，听众一眼可辨</span>
- 轻微润色不要包：水印过密反而稀释信号
