# 五色系 × 大学官方色值对照

> 用户需求：不同大学的视觉识别（VI）色系不同，做某校风格的 slides 前先查本表。
> 官方色值均注明来源；未获官方公开数值的以「近似值」标注并提醒以学校手册为准。
> 可直接复制的变量覆盖块 → `assets/palettes/palette-{purple|green|red|blue|black}.css`。

## 使用流程

1. 问用户/从需求判断目标学校 → 查下表定色系（同系多校时优先用户指定学校）。
2. 打开 `assets/palettes/` 对应色系文件，找到所用主题（v2–v5）的 `:root` 变量块。
3. **追加覆盖法**（推荐，已验证）：把该块整段追加到主题 CSS 文件**末尾**，另存为新主题文件
   （如 `theme-v3-pku-red.css`）——CSS 同名变量后者生效，原主题保持可回滚。
4. **重测对比度**（见文末）：每对「文字色 × 真实底色」≥ 4.5:1 才能交付。
5. 构建：`python3 engine/buildall 讲稿.md -o out.html --theme 新主题.css`。

## 紫 · 南京大学（本 skill 的精神家园）

- 南大紫 C50 M100 Y0 K40 是全链路最可靠的官方值（校规明确）。换算 HEX ≈ `#4D0099`。
- v1/v2 的渐变色块即为南大课堂意象（本 skill 致谢的蒋炎岩老师课程即用此风）。
- 白底直接用南大紫作强调色毫无压力；渐变栏用 紫900→紫500 两档过渡。
- 清华紫偏蓝紫，做清华风格时把渐变与强调统一换成 `#82318E` 基准再派生深浅档。

## 绿 · 武汉大学 / 中山大学

- 珞珈绿 `#115740`（官方 RGB 17/87/64）：偏深的松绿，白底作强调色 8.5:1，安全。
- 中大绿 `#006600`：更纯的绿，大面积色块时略显艳，建议作强调色而非底色。
- 深色主题（v4 墨板）天然适配绿系：把 `--board` 换成 `#1C3A2E`（黑加珞珈绿色相）即可得「珞珈黑板」。
- 注意：绿色作强调时，水印底色用极浅绿（如 `#E8F2EC`），水印字用深绿（≥5:1）。

## 红 · 北京大学 / 中国人民大学

- 北大红 `#94070A`：官方三重色值（CMYK/RGB/HEX），直接可用。v3 纸墨学刊的学术红 `#8C2B2B`
  与其同一气质，换北大红只需改 `--crimson`/`--crimson-deep` 两档。
- 人大红：名称官方但色值未公开，给出近似值并**显式提醒用户**以学校 VIS 手册为准。
- 红系配暖纸底（v3）最有学刊气质；配白底（v5）则成「红色瑞士风」，克莱因蓝的位置全换红。

## 蓝 · 浙江大学 / 武汉大学（珞珈蓝）

- 珞珈蓝 `#002554`（官方）：近藏青，沉稳，对白 15:1，是最稳的蓝。
- 求是蓝 `#003F88`：标准学术蓝；与 v5 克莱因蓝 `#2438C8` 相比更暗更正式，
  换色时 aigc 浅蓝底/深蓝字两档同步换为蓝系的 8%/90% 明度档。
- v5 换浙大蓝后仍保持「单强调色 + 直角细线」的瑞士骨架，气质从设计感转向工科正式感。

## 黑 · 墨色系（无彩通用）

- 不绑定学校：黑白灰 + 单一点缀色（可用目标校色做点缀），任何大学都不违和。
- 两种形态：
  1. **浅底墨字**（v3/v5 骨架）：纸白/纯白底 + `#1F1D1B` 墨 + 可选校色点缀（链接/题号）。
  2. **板底粉笔字**（v4 骨架）：`--board: #1E1E1E`（纯墨黑板），粉笔白 + 黄粉笔不变。
- 黑系是"没有校色时"的默认安全解，也是答辩等严肃场合的稳选项。

## 换色工程注意事项

1. **对比度实测是交付门槛**，不许凭感觉。快速实测（Node/Playwright）：

```js
// 对选择器 el 的 color 与其真实背景色求对比度（向上找不透明底色）
const lum = c => {
  const [r,g,b] = c.match(/\d+/g).map(Number)
    .map(v => { v/=255; return v<=0.03928 ? v/12.92 : ((v+0.055)/1.055)**2.4 });
  return 0.2126*r + 0.7152*g + 0.0722*b;
};
const ratio = (f,b) => (Math.max(lum(f),lum(b))+0.05)/(Math.min(lum(f),lum(b))+0.05);
```

2. 逐对检查：正文/标题/页码/注释/水印字/占位卡字，各自对**真实底色**（注意水印卡、代码块有自己的底）。
3. 深色主题的强调色要**提亮一档**（如粉笔黄 #E8C766 对墨绿板 7.9:1；直接用深绿会 <3:1）。
4. 渐变栏/装饰线无 AA 义务，但两端色差要肉眼可辨。
5. 换完色的主题另存为新文件（如 `theme-v3-pku-red.css`），不要覆盖原主题——保持可回滚。
