# 双方言语法全表

> 引擎 `parser.py` 按「文档中是否出现独立 `---` 行」自动识别方言：有 → 方言 B；无 → 方言 A。
> 全文混用会**整篇**按方言 B 解析，因此一篇讲稿只能选定一种方言，不要中途切换。

## 一、方言 A「人类讲稿」

适合人类手写讲义：标题即分页，写起来最少打断思路。

| 语法 | 效果 | 说明 |
|---|---|---|
| `# 标题` | **封面页**（全幅色块） | 一般只有文档开头一个 |
| `## 标题` | **新内容页**（标题栏） | 每个二级标题开启新页 |
| `### 文本` | 页内小节句（粗体） | 不分页，页面内部结构 |
| `- 文本` | 圆点列表项 | 默认**分步显示**（放映时逐项出现） |
| `- 文本 {nf}` | 列表项，**关闭分步** | no-fragment；该项随页面直接出现 |
| `␣␣- 文本` | 嵌套列表（缩进 ≥2 空格） | 随父项一同显示，不单独分步 |
| `- > 文本` | 列表内 AIGC 卡 | ✦ 水印高亮，等价手写 aigc span |
| `- [ ] / - [x]` | 任务列表 | ☐ / ☑；分步规则同普通列表，可与普通项混排 |
| `1. 文本` | 有序列表 | `start` 取首项号；分步规则同无序；遇非列表行才断开 |
| `> 文本` | **引用块**（容器语义） | 大引号 + 左竖线；内部可含 aigc span（2026-09 语义变更，见下注） |
| `\| 表头 \|` + 分隔行 | **表格** | 下一行为 `\|---\|:---:\|---:\|`，支持左/中/右三档对齐；单元格内行内语法生效 |
| ```` ```lang ```` | **围栏代码块** | 到闭围栏为止；内容原样转义**不做行内解析**；右上角语言徽标 |
| `![说明](url)` 整行 | **真实图片** | 居中图版：限高防溢出、圆角/边框随主题；本地相对路径或网络 URL |
| `[[描述]]`（整行） | 图片占位卡 | 构建时控制台告警行号，提醒补图 |
| `[[...]]`（jyy make-slides 原意） | 请求 AIGC 扩写的记号 | 本引擎渲染为占位卡；若用作扩写请求，扩写后移除记号（见 content-workflow.md 第四章） |

## 二、方言 B「make-slides 产物」

适合 AI 技能批量产出（与 jyy 的 make-slides 产物格式兼容）。

| 语法 | 效果 | 说明 |
|---|---|---|
| `---` | **分页** | 独立成行；出现即整篇按方言 B 解析 |
| `# 标题` | 内容页标题栏 | 每页一个，Title Case |
| `## 标题` | 页内小节标题 | 每页 1–2 个，不要更多 |
| `- 文本` | 圆点列表项 | 分步规则同方言 A |
| `␣␣- 文本` | 嵌套列表 | 缩进 ≥2 空格 |
| `<span class="aigc">文本</span>` | AI 生成水印 | 行内透传，标签白名单（含 `<sub>`/`<sup>`） |
| `> 文本`（可连续多行） | **引用块** | 大引号 + 左竖线容器；连续 `>` 行合并为同一块；内部 aigc span 照常透传 |
| 段落直接写 | 无标题内容页兜底 | `---` 后直接跟内容时自动开页 |

## 三、通用行内语法（两方言共用）

| 写法 | 渲染 |
|---|---|
| `[文字](url)` | 超链接 |
| `**粗体**` | `<b>` |
| `***粗斜体***` | `<b><i>`（主题渲染为粗体 + 着重号） |
| `*着重*` | `<i>`（主题层面渲染为着重号/色彩，不用伪斜体） |
| `` `代码` `` | 行内代码；**最先解析，内容冻结**——`**x**`、`$y$` 等写法可原样展示 |
| `~~删除~~` | `<del>` 删除线（主题渲染为灰色弱化） |
| `![说明](url)` | 行内图片（小图随文；整行独占则升级为居中图版） |
| `<sub>` / `<sup>` | 白名单透传（上下标；也可直接写在 `$...$` 内） |
| `$E=mc^2$` | 行内数学（轻量 TeX，见下方「数学轻量渲染」） |
| `$$...$$`（独立一行） | 展示数学块 |
| `[[描述]]`（行内） | 行内占位标记 `<span class="ph">` |

### 数学轻量渲染（2026-09 增强，同日二次修订：词性分明排版）

`$...$` 内支持两类写法，渲染为 Unicode + `<var>/<sub>/<sup>`（非完整 TeX，零依赖）：

- 上下标：`x_{1:n}` 下标、`0.99^{100}` 上标，也支持单字符 `x_i` / `x^2`（下标内变量同样斜体）；
- 命令映射：`\mid` |、`\prod` ∏、`\sum` ∑、`\forall` ∀、`\in` ∈、`\times` ×、`\approx` ≈、`\neq` ≠、`\leq` ≤、`\geq` ≥、`\ldots` …、`\cdots` ⋯、`\infty` ∞、`\to` →、`\pm` ±、`\cdot` ·；
- 函数名类命令（2026-09 三补，映射为多字母正体文本）：`\log`、`\ln`、`\lg`、`\exp`、`\sin`、`\cos`、`\tan`、`\max`、`\min`、`\lim`、`\gcd`、`\det`——多字母天然走"标识符正体"规则，无需额外标记；
- 根式：`\sqrt{x}` → √(x)，参数允许一层嵌套上下标（`\sqrt{x_{1}}` → √(x₁)）；
  两层以上嵌套不支持（轻量实现边界）；`\frac` 等未收录命令会字面保留，**写前先查本清单**；
- **词性分明**（ISO 80000 / LaTeX 惯例，修复早期"整体斜体"的刻意感）：
  - 单字母变量（`x`、`n`、`c`、`s`…）→ `<var>` 斜体衬线；
  - 函数名/多字母标识符（`Pr`、`concat`、`Base64`…）与数字、运算符保持正体；
  - 特例：`O(` 的大 O 是记号，保持正体；
  - `\mid` 用普通竖线 `|`（U+2223 在 Times/Georgia 缺字形，回退后像斜杠），
    紧贴侧自动补薄空格（U+2009）留气口，已有空格则不补。
- 注意：公式内避免使用 `*`（会被行内着重语法先吃掉）；主题侧 `.math var` 提供斜体样式，
  旧主题未定义时浏览器默认 italic 兜底，向后兼容。
- **断行策略**（"要么整行，要么另起一行"）：行内公式 `white-space: nowrap` 整体不可分，
  行尾装不下时浏览器自动把整个公式挪到下一行（所在容器流不破坏，aigc 卡底色延续）；
  比整个版心还宽的由 runtime `fixMath()` 测量后自动加挂 `.math-block`，升格为独立一行
  居中（行间公式观感；极端超宽以 max-width + 横向滚动兜底）；独立成段的公式直接写
  `$$...$$` 展示块，天然独立居中。

动机：jyy 原版课件曾出现未渲染的 LaTeX 源码裸露（`$P(x_{1:n}\mid c)=\prod_i...` 直接印在幻灯片上）；本引擎保证常用命令都落到可读字符。

### 标准 Markdown 补全（2026-09 第三轮）

引擎在此前标题/列表/引用/占位卡的基础上，补齐了幻灯片场景常用的五种标准块级语法：
**表格（四档对齐）、有序列表（start 起始号）、围栏代码块（语言徽标）、任务列表（☐/☑）、真实图片**；
行内层补齐**粗斜体**与**行内图片**，并把行内代码改为最先解析（内容冻结，与标准 Markdown 一致）。
全套语法的可放映验证稿见仓库 `examples/dialect-test/`（一份稿子测尽所有格式，兼作回归测试）。

实现边界：表格单元格内竖线无法转义（含竖线内容用行内代码包裹）；多行单元格不支持；
同型列表之间仅隔空行不会断开，需隔一个段落；分隔行短横至少两个（`\|---\|`）。

## 四、AIGC 水印规则（jyy 工作流核心）

1. 凡是 **AI 扩写/生成**的内容，源稿必须可辨识：用 `<span class="aigc">…</span>` 包裹，
   或在列表里用 `- > 内容` 简写。主题会渲染出可辨识的水印底色 + ✦ 前缀。
2. **轻微润色不要包**：过密的 aigc 标记会污染版面，反而稀释"如实标记"的信号。
3. **标题（`#`/`##`）内不用 aigc**，即使标题是 AI 生成——保持标题栏干净。
4. 目的：听众永远能分清"讲者的话"与"AI 的话"；逻辑改动时只需修改源码重新构建。

> **`>` 语义变更注（2026-09）**：早期版本 `> 文本` 渲染为独立 AIGC 卡。复刻 jyy
> 《生成式软件工程》开场白时发现原版语义更干净——`>` 是**引用容器**（大引号 +
> 左竖线），AIGC 标记由内部 `<span class="aigc">` 负责，两者正交。现已对齐：
> 引用块不再自动带水印、不再计入分步。历史冻结源稿（lect1/index.md 等）含旧语义
> `>` 金句卡，若需重建请把独立金句卡改写为独立 aigc 段落。

## 五、分步（fragment）行为

- 每个顶层列表项默认是一个分步元素：放映按 `空格/→` 逐项出现。
- `- 文本 {nf}` 取消该项分步。
- 嵌套子项永远随父项出现，不单独计步。
- 构建摘要会输出「N 个分步元素」，可用于估算放映节奏（约 1–2 分钟/页）。

## 六、示例

方言 A（人类讲稿）：

```markdown
# 课程的打开方式

## 这套 slides 如何工作?
- 文本是 source of truth：你看到的其他模态都是 AIGC
- > 完整讲义提供上下文 → Agent 扩写 → Markdown slides → 浏览器渲染
- 如果成功，就"永生"我的操作系统课

## 下一步
- 阅读源码 {nf}
  - 从 parser.py 开始，只有 245 行
  - 再看 render.py 与 runtime.js
- [[一张架构图：讲稿到放映的流水线]]
```

方言 B（make-slides 产物）：

```markdown
---
# Everything is code
## 这套 slides 如何工作?
- 文本是 source of truth：你看到的其他模态都是 AIGC
- <span class="aigc">完整讲义提供上下文 → Agent 扩写 → Markdown slides</span>
---
# 要"永生"的不是一份录像
- 保存可编辑、可 diff、可复现的源代码与构建过程
```

## 七、常见错误

| 错误 | 后果 / 修正 |
|---|---|
| 方言 A 忘写 `# 封面` | 报错 `讲稿必须以 '# 封面标题' 或 '## 页标题' 开头` |
| 全文任何地方出现独立 `---` | 整篇按方言 B 解析，`##` 不再分页——注意分隔线习惯（围栏代码块内的 `---` **不算**，2026-09 起预扫会跳过围栏） |
| 嵌套列表缩进用 Tab | 请用 ≥2 个空格；Tab 不计入深度判定 |
| 表格表头下一行不是分隔行 | 表头被当普通段落——分隔行必须形如 `\|---\|:---:`，短横 ≥2 个 |
| 表格单元格内写裸竖线 `\|` | 会被切分到下一列——含竖线内容改用行内代码包裹 |
| `[[图片]]` 没替换就交付 | 构建有告警，页面留虚线占位卡——交付前清零 |
| aigc 标签写成 `<span class=aigc>` | 白名单要求 `class="aigc"` 带引号，否则被转义为纯文本 |
| 源稿中**展示**字面的 `<span class="aigc">` 文本 | 会被白名单透传当成真标签（未闭合会吞掉后续水印）——展示语法时改用行内代码包裹或文字描述 |
| 引用块与 aigc 卡混淆 | `>` 本身**不带**水印：引用外部需求/他人原话用 `>`；AI 扩写仍需在内部包 aigc span——容器与内容标记正交，不能互相替代 |
| 展示数学 `$$...$$` 期望自动被行内规则识别 | **不能**——`$$` 块级触发后，内部内容只走 `render_math(esc(...))`，不再过 parse_inline；写裸 LaTeX 命令请查「数学轻量渲染」映射表 |

### 引言块里的 aigc（2026-09 修订）

引用块作为容器后，`blockquote.quote .aigc { background: transparent }` 是基线
（详见 design-system.md 与 lessons-learned.md A10）——容器已暗示"摘录/引用"，
再叠紫底是双重视觉重音。规则：

- 引用块内的 aigc：**保留** `✦` 前缀与紫色字（信号不丢），**去掉** 浅紫底色；
- 裸段落里的 aigc：仍用满强度浅紫底作为唯一标记（v2 主题默认行为不变）。

如需恢复紫底（如做"双标记"语义对比稿），由具体 override 重新加回即可。
