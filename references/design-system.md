# 设计系统：中文学术幻灯片规范 + 五主题风格档案

> 本文浓缩自《中文 PPT 与网页设计调研笔记》并经 v1–v5 五版实战验证；
> 每条规则标注笔记出处（如 [1.4]），便于溯源。选主题、调样式、审稿时读本文。

## 一、排版规范（写稿与调主题共用）

### 1.1 字号梯度（1280×720 基准，出处 [1.4]）

| 层级 | 档位 | 说明 |
|---|---|---|
| 页面标题 | 40–48px | 五主题在 40/42/44/48 内取值形成性格 |
| 页内小节 | 30px | 介于标题与正文之间 |
| 正文 | 28px（默认 32，高密度稿取下限 28） | 投影可读下限 |
| 注释/页码 | 20–24px | **低于 20px 投影读不清** |

字重只用三档：400（正文）/ 600（标记）/ 700（标题），克制即秩序。

### 1.2 留白与行宽

- 安全边距 = 高度 × 5% ≈ 36px [1.2]；左右边距 52–76px（越"学术"越宽）。
- 中文正文行高 **1.7–1.8** [2.8雷10]；标题行高 1.2–1.3 [1.4]。
- 行宽 ≤ 37 个汉字（学刊标准）[2.3]；字间距**只加在标题上**（.02–.05em）[3.7]。

### 1.3 中文排印红线（逐条都是踩过的坑）

1. **纯黑 `#000` 禁止**：用带色相的深墨（如 #2B2735、#2A2520），黑得有温度 [3.3]。
2. **避头尾**：`line-break: strict`，禁 `break-all`，长 URL 才 `overflow-wrap: break-word` [3.7]。
3. **em/i 不用伪斜体**：中文斜体是排印灾难，用着重号（`text-emphasis`）或色彩替代。
4. **对比度 ≥ 4.5:1（WCAG AA）**：所有文字色对**真实底色**实测，装饰线不设限。
5. **色数封顶**：中性色打底 + 单一强调色，全稿 ≤ 3 色 [3.3]；国人色调偏好：黑白灰 > 艳 > 亮 > 浅。
6. **深色模式的黑要加色相**：黑板用墨绿 #24352C 而非 #111 [3.3]。
7. **辅助灰不得深于 #767676 临界线**（对白底 4.5:1）[2.8雷1]。

### 1.4 动效与打印

- 动效仅限分步渐显（opacity/位移 ≤ 8px），必须包 `@media (prefers-reduced-motion: reduce)` 关闭。
- 打印导出：`@page { size: 1280px 720px }` + `print-color-adjust: exact`，每页一纸。

### 1.5 引用块与 AIGC 标记的语境降级（2026-09 新增）

引用块（`blockquote.quote`）是"摘录/引用"容器，AIGC 水印（`aigc` span）是"AI
生成"信号。两者叠加时按"容器优先"原则做视觉降级：

| 容器 | AIGC 视觉强度 | 字号 | 设计动机 |
|---|---|---|---|
| 裸段落（默认） | **满强度**：浅紫底 `#EFEAF8` + 紫色字 + ✦ 前缀 | 正文 28px | 段落里唯一标记手段，必须能跳出来 |
| 引用块内 | **降级**：背景透明 + 紫色字 + ✦ 前缀（**不丢** ✦） | 24px（小一档） | 容器已暗示"摘录/引用"，再叠紫底是双重标记，视觉噪音大于信号 |

**实现**：
- v2 主题本体已把 `blockquote.quote` 的字号基线设为 24px，并把
  `blockquote.quote .aigc { background: transparent }` 写进基线（v2 主线 §六）
- 具体主题（紫檀·南大复刻等）按需追加容器装饰（浅底 / 左竖线 / 大引号），
  但 aigc 降级规则不撤回——避免"复刻稿把全局正确的修正又改回去"
- 例外：做"双标记语义对比稿"等明确需要时，由具体 override 重新加回紫底

**规则**：AIGC 信号（✦ + 紫字）恒在，**底色强度**跟随容器语境自适应——"标记的克制即秩序"。

### 主题设计的"完全分野"方法论（v2 → v3 的经验）

做"同一内容源的另一种面孔"时，把变量隔离到纯设计维度：**内容源稿逐字不动**，
只在底色/字体/主色/骨架/页码/列表符/着重号/行高 8–9 个维度上与旧版完全分野，
每条规则标注出处。这样 A/B 对比才纯粹，也方便回滚。

## 三、配色公式（把任何大学校色装进主题）

```
底色（中性）→ 正文墨（带色相深灰）→ 强调色（校色，全稿唯一彩色载体）→ 三色封顶
```

- 强调色承担：题号、链接、着重号、列表符、细线——**一个色包办全部强调**，不加第二个彩字。
- 校色是深色（如北大红 #94070A）：直接作强调色，底色保持白/纸。
- 校色是中等明度（如珞珈绿 #115740）：作强调色；若要大面积色块，先加白提亮一档并实测对比度。
- 深色主题（黑板）：板底 = 黑 + 校色色相（如墨绿板），粉笔白 + 校色的亮化色作强调。
- **每一次换色都必须重测对比度**：文字色对真实底色 ≥ 4.5:1（正文）/ 3:1（大字号标题可放宽到 AA Large）。
- 标题编号用「N.」或纯数字；**不要用 § 符号**（西文法律引用符号，中文语境不适用）。
